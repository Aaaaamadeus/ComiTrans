# 断点续传

“翻译偏好 → 断点续传：跳过已完成页面”默认开启。网络失败或手动停止后，再次点击开始即可继续；关闭程序后，重新添加相同原文件、选择原输出目录并开始，也会读取之前的进度。

恢复按页进行，支持单张图片、图片批量任务和整本 PDF：

- 已完成且译图、清理底图、布局 JSON 完整的页面会跳过检测、OCR、翻译与排版。
- 已收到完整译文但尚未完成排版的页面，会重新检测和 OCR；识别文本与缓存一致时直接使用保存的译文，不再发起翻译请求。
- 同批其他页面失败时，成功返回的译文和已完成页面仍会保存。
- PDF 继续使用原精修资料目录，全部页面成功后再合成整本文件。

例如第 80 页失败，前 79 页已完成：再次开始会从未完成页继续。日志会显示“跳过 … 页已完成结果”和“复用已保存译文”，页数进度也会包含已恢复页面。

要完整重译，取消勾选续传后开始。关闭开关的任务仍会记录新进度；若该任务中断，重新勾选即可续传。原文件内容、翻译模型、目标语言、提示词、字体或其他影响输出的配置改变时，会建立新进度。更换 API Key、并发数或界面语言不影响续传。

进度保存在输出目录的 `.comitrans-resume` 中，其中包含逐页译文和完成标记，不保存 API 密钥。不要删除它或 PDF 的精修资料目录，否则会失去对应恢复信息。每个输出文件保留最近一次任务的进度，移动原文件或更换输出目录会作为新任务处理。旧版本生成且没有进度记录的结果不会直接视为已完成。

输出文件丢失或损坏时会重新生成该页；缓存损坏时会重新开始。强制退出发生在接口响应尚未落盘的瞬间时，该请求仍可能需要重发。此功能不能恢复服务端已经计费但客户端未收到的响应，也不替代接口自身的重试机制。
