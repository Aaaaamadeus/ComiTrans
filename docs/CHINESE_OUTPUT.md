# 译文简繁切换

翻译页顶部“原文语言”旁新增 **译文** 选择框：

- **简体中文**：旧配置和新配置的默认选项，保存为 `target_language: zh-Hans`。
- **繁體中文**：保存为 `target_language: zh-Hant`。

选择后自动保存，重启后恢复，并用于后续图片和 PDF 翻译。运行与模型预热期间锁定选择；同一批任务使用启动时的配置。切换可以复用已加载的本地模型，保持当前字体选择及已有译文和精修草稿。字体预览文字跟随简繁选项更新。

## 翻译与输出

首次翻译、整页图片辅助翻译、降级为纯文本，以及截断后的续传请求，都明确使用所选的目标字形。模型完成返回后，本地再次规范化译文，包括中文人名和术语；保留条目顺序、空字符串、英文、数字、标点和换行。

规范化使用 [OpenCC 纯 Python 实现](https://github.com/yichen0831/opencc-python)及其字典。繁体采用 `s2t` 通用繁体字形，简体采用 `t2s`。程序随附转换配置、字典、NOTICE 和许可证，转换过程在本机执行。源码环境依赖固定为 `opencc-python-reimplemented==0.1.7`，安装项目运行依赖即可使用。

如需繁体字形的字体，可直接在“译文字体”中搜索“繁体”，选择应用内置的源泉圆体 TW、芫荽、霞鹜文楷 TC、思源黑体/宋体 TC 等。[内置繁体字体清单](TRADITIONAL_MANGA_FONTS.md)。
