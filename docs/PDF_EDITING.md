# PDF 翻译与精修

翻译 PDF 时先读取页数和尺寸，再按在途页数上限按需生成原分辨率 PNG，避免整本预渲染的长时间等待。当前页修补时，后续页可继续准备和翻译；并发设置限制全部在途页数，完成一页再补入下一页。断点续传复用有效页图和已完成结果；取消时保留已有资料并停止后续预取。实际设备与各阶段耗时会写入日志。性能与复现见 [翻译性能记录](TRANSLATION_PERFORMANCE.md)。

选中气泡后，可用 **还原此气泡** 同时撤销该块的修补与嵌字，恢复项目 `source/` 中对应页的原始像素；保存后导出 PDF 会保留还原状态，也可再次切回处理结果。详见 [气泡还原说明](BUBBLE_RESTORATION.md)。

翻译整本 PDF 后，可以从结果页进入“嵌字精修”，也可以重启后点击“导入译图 / PDF”打开译文 PDF 或资料目录中的 `project.json`。精修始终以独立图片操作，打开、切页、改字和保存图片都不会合成 PDF。左侧按原顺序显示各页，支持改译文、字体、字号、蒙版与背景修补。

- **连续长条**：所有已导入页面纵向排列，滚轮浏览，点击页面后在原位置编辑。适应模式按页面宽度显示；也可以使用固定倍率。屏幕外的非当前页会释放预览缓存。侧栏缩略图和长条非当前页预览按可见范围在后台解码；预览尺寸上限只用于屏幕显示，不影响原图、修补输入或导出清晰度。
- **保存图片**：保存当前页的译图、布局 JSON，以及有背景修补时的清理底图。切页时有未保存修改会询问保存、放弃或取消。
- **导出 PDF**：选择文件名，保存当前页，再在后台用该图片项目的所有已保存页合成 PDF。默认另存为 `_edited.pdf`，保留页数、页序、原始物理尺寸和完整页图像素，使用无损压缩。也可将普通导入图片按列表顺序导出（物理尺寸按 200 DPI 换算，不重采样）。
- **取消导出**：可随时发出取消请求，在页间响应；失败或取消会删除临时文件，不替换原有 PDF，也不删除已保存图片。导出期间暂不能保存、切页或退出，避免同一本书混入不同时间的页面；界面继续响应，完成或取消后恢复。

输出示例：

```text
漫画_translated.pdf
漫画_translated.comitrans.json
漫画_translated_edit_<独立编号>/
  project.json                    # 原文件名、原始页面尺寸与顺序
  source/page_0001.png             # 原始 PDF 页图
  translated/page_0001.png         # 可供合成 PDF 的译图
  translated_cleaned/page_0001_cleaned.png
  translated_layout/page_0001_layout.json
```

请将 PDF、同名索引和资料目录一起移动，保持相对位置。索引会指向最近一次成功翻译的资料目录；启用断点续传时继续使用对应资料目录；取消续传或更改翻译配置后重译会生成独立目录，旧版精修不会被覆盖。确认不再需要后，可自行删除未被索引引用的旧目录。

翻译失败或取消时，已经完成的页面资料也会保留，位置记录在日志中；可直接导入其中的译图继续精修。未完成的整本任务不会替换之前成功的 PDF。PDF 导出失败时，已保存的页面修改仍保留，可以排除文件占用等问题后重试。

旧版本已经清除的临时资料无法从译文 PDF 恢复。此类文件需要重新翻译一次，才能生成完整精修资料。PDF 页面内容仍按图片处理，不保留原 PDF 的可选中文本或矢量对象。

单独导出的 PDF 是成品文件；继续编辑请打开原资料目录的 `project.json` 或其中的译图。原译文 PDF 的索引只用于定位资料，已打开的图片项目不会随同名 PDF 的重新翻译而切换。


## 大项目与操作状态

打开 PDF 项目时，页面索引和图像解码在后台执行。连续长条只为视口附近页面及当前编辑页保留画布，侧栏最多缓存 128 张缩略图；1000 页不会创建 1000 个画布。缩略预览仅用于显示，当前页编辑、背景修补和导出保留原像素。

切页加载期间仍可编辑当前页；如果有新修改，加载结果会被放弃，以免覆盖草稿。快速选择多个页面时仅排队最后一次选择。保存图片在后台执行，保存期间产生的新编辑会继续显示为未保存；通过保存后切页或关闭窗口触发的操作，会等最新修改保存成功再继续。失败时保留草稿与当前页。

窗口变窄时只显示一个侧栏，点击另一侧栏可切换；恢复宽窗口时重新显示手动选择的侧栏。专注模式不改变这一偏好。翻译偏好展开后在栏内滚动，修改会自动保存，并在收起、切换功能页和退出前刷新；失败时显示原因并可重试。

完整复现方式、100/500/1000 页合成测试结果与适用范围见 [精修性能说明](EDITOR_PERFORMANCE.md)。
