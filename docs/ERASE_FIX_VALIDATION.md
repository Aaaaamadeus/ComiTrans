# 白气泡擦字修复实测

下列数据记录的是首次纸色平涂实验。当前构建另有受限补擦：只在文字种子附近补涂合适的连通块，保留稀疏装饰网点。下列数据未用于评估这次补擦变更。

原图中浅色且均匀的气泡常带 JPEG 噪声，气泡边线也会进入框外采样环。以整圈像素的最大色差判定可否平涂，使 12 页日漫上全部 106 个框都进入 LaMa。修复在生成最终掩膜后检查框内剩余纸面，要求有足量样本、九成纸色像素在中位色的 3 级内、99% 在 10 级内，同时核对笔画附近及框外背景估色。通过时只向已有擦除掩膜填入测得的纸色。旧的纯色识别仍可处理黑底和彩底。

在同一批原尺寸页面上，对每版分别固定其检测框、字号、种子、LaMa 权重与设备，调用生产代码 inpaint_bubbles 比较修复前后。12 页主样本及 2 张额外页面仅供本地评测。每张页图的新旧掩膜逐像素一致，掩膜外灰度逐像素等于输入。没有修改模型权重，未调用翻译 API。

| 同批样本 | 修复前 | 修复后 |
|---|---:|---:|
| v2.5.1 主样本平涂框 | 0/106 | 40/106 |
| v2.5.1，50 个 A 类气泡，纸面灰度标准差中位数 | 3.56 | 1.94 |
| 同组标准差 ≤ 2 的框 | 8/50 | 27/50 |
| 同组出现新增暗像素的框 | 17/50 | 8/50 |
| v2.5.1，54 个 B 类框，纸面标准差中位数 | 5.94 | 5.99 |
| v2.5.0 主样本平涂框 | 0/104 | 62/104 |
| v2.5.0 有效测量框中，纸面标准差 ≤ 2 | 26/105 | 69/105 |

v2.5.0 的 104 为实际走擦字分支的框数，105 为可做像素比较的检测框数，两者分母不同。A/B 使用交接报告归档的分组。B 类中包含图案和网点，平整度不能单独作为质量评分。两张扩展页均在实际尺寸处理，并查看了网点页三态对照。没有真实无字底图。

**指标更正**：审计脚本的 `cur_left` 计数条件是「原灰度 ≥170，擦后 <140」，衡量新增暗像素。它不能直接测出仍可读的原文。另记原深色像素擦后仍深的总数，其中包含画面和边框，不能换算成字符残留率。独立试验的局部连通块补擦只额外覆盖了 23 个原深色像素，未将扩大掩膜纳入发行算法。未检出或未被掩膜覆盖的文字仍可能保留。

逐项数值见 [机器记录](models/white-paper-erase-validation.json)。重复对比应使用新的输出目录，避免复用已完成页。
