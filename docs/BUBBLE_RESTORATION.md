# 按气泡还原原图

在“嵌字精修”右侧选中一个文本块，点击 **还原此气泡**。该块的译文会隐藏，原气泡框内的像素以及属于它的擦字边缘会从处理前原图复制回来。点击 **保存图片** 保留结果，关闭后再打开仍有效。PDF 项目同样先保存页图，再按需 **导出 PDF**。

译文、字体、位置和字号继续保留。按钮会变为 **恢复处理结果**，可随时切回处理后的底图与嵌字。还原状态下暂停修改该块的排版；其他气泡仍可编辑或独立还原。自选修补如果覆盖已还原区域，会要求先切回处理结果，避免生成被原图遮住的修补。

## 原图与清晰度

- 新生成的普通图片结果自动保存一份无损原图，位于输出目录旁的 `<输出目录名>_original/<结果名>_original.png`。移动精修资料时一起保留原图、清理底图和布局目录。
- PDF 项目直接复用 `source/page_0001.png` 等已有页图，不重复复制整本原图。
- 旧结果没有原图时，通过 **关联原图** 选择该页处理前的图片。尺寸必须完全一致；不会缩放或猜测缺失像素。尺寸一致只能保证坐标对齐，请确认选择的是同一页。
- PNG 结果原位保存。JPEG 等其他格式的结果在使用还原后另存为 `<结果名>_restored.png`（重名则增加编号），并保存配套资料；旧文件保留。后续继续编辑该 PNG，避免有损压缩改变原始像素。
- 还原使用最初检测到的气泡框，不随译文移动或缩放。原框内精确恢复原始像素，包含被擦掉的原文、线稿和背景；该块移到框外的译文也会隐藏。

相邻气泡的原框会受到保护，避免擦字边缘误覆盖邻框；若原检测框本身重叠，明确还原的原图区域优先，因此交叠部分可能覆盖另一块的嵌字。

## 布局数据

每个文本块可保存 `restore_original: true`，原有 `text`、字体和排版设置不变。`original_region` 的版本为 `1`，包含页面像素坐标 `box` 和 Base64 PNG 二值掩膜 `mask_png`；范围是原气泡框与该块实际擦除像素的并集。清理底图不被还原操作覆写，因而保存之后仍可切回处理结果。

旧布局首次还原时，在原框外 15 像素范围内比较原图与清理底图，补回变化的擦字边缘，并保存得到的区域。这是旧数据的兼容方式；新输出记录实际擦除区域。切页或退出前放弃未保存修改，不会写入还原状态。
