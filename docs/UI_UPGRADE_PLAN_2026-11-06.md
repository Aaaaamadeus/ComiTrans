## 0. 一页结论

| # | 用户反馈 | 代码根因 | 方案 | 优先级 |
|---|---|---|---|---|
| 1 | 画布不能像 PS 那样拖拽/缩放，只能下拉选倍率，来回切比例很烦 | 缩放只有 5 个预设（`editor_page.py:230`），画布只处理蒙版拖拽（`preview.py:158`），全工程无 `wheelEvent` | 滚轮以光标为锚点缩放、空格/中键平移、双击切换适应/100%、缩放 HUD + 快捷键 | P0 |
| 2 | 「文本与排版」窗口太小，只能看到 3 行 | 气泡列表写死 96px（`editor_page.py:335`），窄窗 60px（`:1615`）；原文框 76px、译文框 96–180px；右栏最大 420px（`:319`） | 右栏改纵向分栏可拖拽、区间随窗口增长、译文框自适应、全屏编辑 | P1 |
| 3 | 画布上的气泡点不了，只能在小列表里来回滑 | 画布只画当前选中块的蒙版框，没有其它块的命中测试；列表是唯一入口（`editor_page.py:336`） | 画布命中测试 + 悬停高亮 + 点击选中 + 重叠循环 + 双向滚动同步 | P1 |
| 4 | 全白界面刺眼，想要夜间模式 | `COLORS` 单套写死（`theme.py:8`），样式表在 import 时一次性生成（`:181`），另有 41 处硬编码色值 | 三层语义令牌 + 「夜墨」深色主题 + 跟随系统 + 设置页即时切换 | P0 |

**一句话**：先修「手感」（画布）和「眼睛」（深色主题），再修「空间」（右栏）和「入口」（点选）。四项全部落在精修页，互不阻塞，可按 P0→P1 分两次发版。

- 不做多选气泡批量改字（P2 再议）。

## 2. 现状诊断

### 2.1 画布（反馈 1）
- 缩放入口只有一个下拉框：适应页面 / 50 / 100 / 150 / 200（`editor_page.py:230-234`），选中后调用 `preview.set_zoom()`（`:504`），状态按**索引**记忆（`:532`、`:541`）。
- `ImagePreview` 用 `QScrollArea + QLabel`，每次换档都整页重采样成一张新 QPixmap（`preview.py:448-461`）：
  - 200% 下 1600×2400 页 ≈ 3200×4800 位图 ≈ 61 MB，400% 会超过 240 MB；
  - 因此现在也没法提供连续缩放，只能给 4 个档位。
- `PageCanvas.mousePressEvent` 只处理蒙版框的创建/移动/缩放（`preview.py:158-177`），没有平移；全工程无 `wheelEvent`（已检索确认）。
- 连续长条模式的点击只做「切换页面」（`strip_preview.py:280-284`），没有视图手势。
- 对比：PS / Figma 的标准手感是「Ctrl+滚轮以光标为中心缩放、空格拖拽平移、双击切换适应/100%」。当前一项都没有。

### 2.2 右栏（反馈 2）
| 部件 | 现状 | 后果 |
|---|---|---|
| 气泡列表 | `setFixedHeight(96)`（`:335`），窗口高 <700 时 60（`:1615`） | 每行约 32px，**只能看 2–3 行**；20 个气泡要滚 7 屏 |
| 原文框 | `setFixedHeight(76)`（`:375`） | 日文长句只有 2 行可见 |
| 译文框 | `min 96 / max 180`（`:394-395`） | 长段落内部滚动，看不到上下文 |
| 右栏宽度 | min 280 / max 420（`:318-319`） | 1440 窗口下右栏只有 360，列表与表单都挤 |
| 空白 | 「译文编辑」页 `addStretch(1)`（`:400`） | 内容被推到上下两端，中间大片空白（截图可见） |
| 自动滚动 | `_reveal_text_editor` 在窄窗滚动到输入框（`:592-595`） | 抬头只剩输入框，**气泡列表直接滚出视野**——这正是反馈 3 的成因 |

### 2.3 选中（反馈 3）
- 选中唯一入口是 `block_list.currentRowChanged`（`:336`）。
- 画布只为「当前选中块」画一个指导框（`preview.py:289-304`），**其它气泡在画布上是不可见的**，既不知道有几块，也点不中。
- 连续长条下点击只会换页，不会选中气泡。
- 列表项文本只有 `01  摘要前 28 字`（`:939-944`），没有状态、没有悬停反馈、没有编号徽标。

### 2.4 主题（反馈 4）
- `COLORS` 单套：`paper #FFFFFF`、`workspace #F8F8F8`、`canvas #F3F3F3`（`theme.py:8`）。
- `APP_STYLESHEET` 在模块导入时把 `@token` 一次性替换掉（`:181-183`），运行期无法换色。
- `install_ui_font()` 只装一次 QPalette（`:63-73`），`MainWindow` 再 `setStyleSheet(APP_STYLESHEET)`（`main_window.py:119`）。
- **41 处硬编码色值**，分布在 6 个文件（见 §4.5）：`#FFFFFF` 画布底、`#F8F8F8` 侧栏标题底、`#111111` 标签文字、`#777777` 编号、`#595959` 说明、`#607D8B` 蒙版虚线、`#B8B8B8` 滚动条/复选框描边、`#D0D0D0` 节点轨道。
- 图标 3 个 SVG 全是 `stroke="#111111"`（`assets/ui/icons/*.svg`）→ 深色下不可见。
- 空状态插画是黑线透明 PNG → 深色下不可见。

## 3. 设计目标

### 3.1 三条原则
1. **作品优先**：画布与漫画像素是主角，界面越安静越好；任何装饰不得进入导出图。
2. **手感优先于整齐**：画布交互对齐 PS/Figma 的肌肉记忆，宁可多一个手势，也不让用户去找下拉框。
3. **黑白身份不变**：浅色「纸白」、深色「夜墨」，两套都只有灰阶 + 一个只在画布上出现的「指示蓝」；不引入彩色品牌。

### 3.2 主题方向
- **纸白（现有）**：白纸 + 纸灰画布 + 细网点头部，保留。
- **夜墨（新增）**：暖中性灰（不是 slate 蓝灰），面板浮在更暗的工作区上，画布最深；像深夜暗房里看一张白色画稿。
- 深色下**绝不**给漫画图加任何滤镜或蒙层；页面亮度不变，只换周围环境。

## 4. 设计令牌与深色模式

### 4.1 三层令牌
```
基础色（palette） → 语义令牌（surface / text / border / guide…） → 组件引用
```
- 组件只允许引用语义令牌，禁止再写 hex。
- 令牌以 dataclass `Theme` 承载，`build_stylesheet(theme)` 生成 QSS，`apply_theme(app, mode)` 设置 QPalette + QSS + 通知自绘控件重绘。
- 保留 `install_ui_font(app)` 作为兼容入口（内部调用 `apply_theme`），避免一次性改动 smoke_test / review 脚本。

### 4.3 落地方式
1. 重写 `theme.py`：`PALETTES`、`Theme`、`build_stylesheet(theme)`、`apply_theme(app, mode)`、`theme()` 取值函数、`theme_changed` 信号。
2. 自绘控件（`PanelHeading`、`StageFocus`、`PageCanvas`、节点轨道、色板、网点）改为从 `theme()` 取色，并连接 `theme_changed` → `update()`。
3. 图标改为运行期着色：读 SVG 文本替换 `stroke` 颜色 → `QSvgRenderer` 渲染到 QPixmap，按 (path, color, size, dpr) 缓存；`check.svg` 的白色描边映射到 `paper`。
4. 主按钮在深色下自动变成「浅底深字」——现有 QSS 的 `background:@ink; color:@paper` 语义正好可复用，不需要写两套按钮样式。
5. 设置页新增「外观」分组：主题（跟随系统 / 纸白 / 夜墨）、画布底色（纸灰 / 深灰 / 纯黑）、减少动效（P2）。写入 `config.yaml`：`ui_theme`、`canvas_tone`、`ui_reduced_motion`。
6. 跟随系统：PySide6 6.11 支持 `QGuiApplication.styleHints().colorScheme()` 与 `colorSchemeChanged`（本机已验证可用），变化时自动切换。
7. 切换即时生效，无需重启（界面语言才需要重启，保持现状）。

### 4.4 深色下的特殊资产
| 资产 | 问题 | 处理 |
|---|---|---|
| 3 个 SVG 图标 | `stroke #111111` 在黑底不可见 | 运行期着色（§4.3-3） |
| 空状态插画（2 张 2 MB 透明 PNG） | 黑线透明图在深色上面消失 | 深色下垫 `paper` 圆角卡片（16px）再画；后续可用 ComfyUI 生成深色变体（P2，素材规范见 `assets/ui/illustrations/README.md`） |
| 网点 | 黑点黑底 | 反相为浅点 + 透明度 0.22 |
| 文字颜色选择器 | 边框 `#888888`、默认色 `#000000` | 边框走 `ruleStrong`；默认色属于排版数据，**不随主题变** |
| 水印预览 | 半透明黑字 | 保持数据色，不随主题 |
| Skribble 字标 | 黑色字 | 深色下取 `ink`（浅色），仍保持单色 |

## 5. 画布交互（反馈 1）

### 5.1 手势与控件
| 操作 | 行为 |
|---|---|
| `Alt + 滚轮` | 以**光标位置**为锚点连续缩放（5%–800%，与 PS 一致；`Ctrl + 滚轮` 作为别名同样生效） |
| `滚轮` / `Shift + 滚轮` | 纵向 / 横向滚动（保持现在的滚动行为） |
| `空格 + 左键拖动` | 临时抓手平移（PS 逻辑：松开空格恢复原工具，光标恢复） |
| `中键拖动` | 平移 |
| `左键拖动`（空格未按住） | **不平移**；预留给后续气泡点选 |
| `H` | 抓手工具常驻开关（画布有焦点时生效） |
| 双击空白处 | 适应页面 ⇄ 100% |
| 右键 | 视图菜单：适应页面 / 适应宽度 / 100% / 200% / 画布底色 / 显示辅助线 |
| 工具栏 | `[−] [128% ▾] [+]` + `适应` 按钮；下拉里保留 50/100/150/200 与「适应宽度」 |
| 缩放 HUD | 缩放时右下角浮出 `128%` 胶囊，600ms 后淡出；不常驻 |

### 5.2 缩放模型
```python
@dataclass
class ViewState:
    mode: Literal['fit_page', 'fit_width', 'actual', 'custom'] = 'fit_page'
    factor: float = 1.0          # 仅 custom 有效
    anchor: QPointF | None = None  # 画布内像素锚点，重排后不跳
```
- `fit_page`：`min(viewport/page)`，留 24px 边距；
- `fit_width`：`viewport.w / page.w`；
- `actual`：1.0（按物理像素，DPR 由绘制处理）；
- 缩放围绕光标：`image_pt = (scroll + cursor - page_origin) / old_scale`，重算后 `scroll = page_origin + image_pt * new_scale - cursor`，再夹到合法范围。
- 状态持久化改存 `ui/editorView`（JSON：mode + factor），不再存索引，避免档位变化后错位。

### 5.3 渲染改造（关键，决定能不能上 400%）
- 新增 `PageViewport(QAbstractScrollArea)`：`paintEvent` 只绘制**可见源矩形**：
  `painter.drawPixmap(target_rect, pixmap, source_rect_in_image)`；不分配整页放大位图。
- 复用现有 `PageCanvas` 的蒙版交互逻辑（提成 `RegionOverlay` 混入），保留信号 `region_edited` / `region_edit_finished`。
- 页面绘制：`pageEdge` 1px + 24px 软阴影（多层透明矩形，不用 `QGraphicsDropShadowEffect`）+ 画布底。
- 高 DPI：`drawPixmap` 目标尺寸取整到设备像素，`SmoothPixmapTransform` 仅在缩小或非整数倍时开启。
- 连续长条模式：保留现有 `_StripScroll`（已经是视口绘制），补 `Ctrl+滚轮`（按活动页锚点）与空格平移即可。

### 5.4 手势冲突矩阵
| 位置 | 左键拖动 | 中键 / 空格+左键 |
|---|---|---|
| 蒙版边角（8 个把手） | 改大小（现有） | 平移 |
| 蒙版框内 | 移动蒙版（现有） | 平移 |
| 其它气泡上 | 选中该气泡（§7） | 平移 |
| 页面空白 | 不响应（P1 点选前）；空格或中键才平移 | 平移 |
| 框选背景（修补模式） | 画框（现有） | 平移（禁用框选） |

规则：**把手 > 蒙版 > 其它气泡 > 平移**；任何时候 Esc 取消本次拖动并回到拖动前坐标。

### 5.5 边界与性能
- 缩放上限 800%，下限 5%；页面小于视口时居中且禁用平移（视觉上不抖）。
- 内存：不再产生 >64 MB 的中间位图；400% 下只多一次可见区域采样。
- 帧预算：缩放重绘 <16ms（1080p、1600×2400 页）；滚轮事件节流 8ms。
- 空状态：保留现有插画 + 「导入已翻译图片或 PDF」入口，深色下加纸卡（§4.4）。

## 7. 画布选中气泡（反馈 3）

### 7.1 命中与悬停
- `EditorPage` 把全部块的矩形（`mask_box` 优先，否则 `box`）以图像坐标传给视图：`set_regions([{index, box, restored}])`。
- 视图缓存屏幕矩形，鼠标移动时做反向遍历命中（后画的在上），容差 4px；≤200 块时单次 <0.2ms。
- 悬停：`guide` 1px + `guideHalo` 外圈 + 6% 填充；光标 `PointingHandCursor`；tooltip 显示 `03 · 译文首行`（超过 40 字截断）。
- 悬停仅做视觉，不改变选中，不触发排版重算（避免鼠标划过就重绘文字）。

### 7.2 选中态
- 双描边：外圈 `guideHalo` 2px + 内圈 `guide` 1.5px（深浅主题、黑白画稿上都能看清）。
- 8 个把手从 7px 提到 9px（逻辑像素），高 DPI 下按 DPR 取整，最小 10 设备像素。
- 左上角编号徽标：`01` 等宽 11px，`ink` 底 `paper` 字，向上偏移 18px，与列表编号一一对应。
- 选中不同块时，旧块先 `_store_properties()` 落盘再切换（现有逻辑已如此，需保持）。

### 7.3 重叠气泡
- 命中多个时按面积从小到大排序（小的更可能是内层气泡）；重复点击在同一位置循环。
- `Alt + 点击` 反向循环。
- 命中 >1 时画布右下角提示一次 `2 个气泡重叠 · Alt+点击切换`（3 秒后消失）。

### 7.4 双向同步
- 画布点击 → `block_list.setCurrentRow(index)` + `scrollToItem(EnsureVisible)`。
- 列表选择 → 视图 `ensure_region_visible(index)`（放大状态下把该块滚进视口，边距 80px）+ 240ms 高亮脉冲（开启「减少动效」时只做静态高亮）。
- 换页 / 换块 / 隐藏蒙版 / 拖拽结束时取消悬停与拖拽状态（沿用 `cancel_region_drag` 的时机）。

### 7.5 可访问性
- 视图 `setAccessibleName('漫画画布')`（已有）+ 选中块播报 `第 3 块，共 20 块`。
- 键盘可达：`Alt+↑/↓` 切块、`F2` 全屏编辑、`Esc` 取消选中/拖拽、`Ctrl+0/1/2` 视图。
- 颜色不是唯一标识：选中同时有描边、编号徽标、列表高亮。

## 8. 全应用视觉统一（美化）

### 8.1 排版
- 字级固定为 12 / 13 / 14 / 15 / 17 / 20 / 24 / 28（现在混用 12/13/14/15/17/18/20/24/28，收敛到 8 档）。
- 正文最小 14px（插件规范：≥14）；长文输入 15px，行高 1.6（`QPlainTextEdit` 需用 `QTextBlockFormat.setLineHeight`，见 §12 风险）。
- 数字与坐标统一等宽（JetBrains Mono / Consolas），编号 `01` 与内容对齐。

**字体回退链（P0-0，先修）**
- 现状：`ui_font()` 只从系统字体挑；五档候选全缺时（offscreen 截图环境就是），Qt 退到唯一注册过的中文字体——Aa 手写日志体，整个界面变成手写风。
- 已验证的修法：注册仓库里**已随包发布**的 `comic-translate-ai/font_file/CN/SourceHanSansSC-Medium-2.otf` 后，同样无系统字体的环境下 `ui_font()` 解析为 `Source Han Sans SC`（不增加包体）。
- 规则：手写体 `AaJinRiHuaQing` 只允许给 `log_font`，Skribble 只允许给 `brand_font`，两者都不得进入全局回退；缺系统字体时兜底到内置思源黑体。
- 截图管线：`review_ui.py` / `review_large_editor_ui.py` 在写盘前断言 `QFontInfo(ui_font()).family()` 属于白名单，否则直接失败，避免再产出误导性截图。

**装饰降噪（回应「晃眼」）**
- 分区标题右侧网点：透明度 0.46 → 0.30，宽度 96/168 → 72/120。
- 空状态插画 300×210 → 240×168；深色下垫纸卡。
- 页签、工具栏各自只保留一条分隔线；字符图标（`＋`、`○`、`●`、`▸`）全部矢量化为 20px 线性图标。
- 背景纹理只出现在分区标题与画布留白，正文、列表、输入区一律干净。

### 8.2 图标
- 补齐一套 20px 线性 SVG（Phosphor 风格，1.75px stroke）：放大、缩小、适应页面、适应宽度、抓手、上一个、下一个、展开面板、收起面板、全屏编辑、重置、主题、更多。
- 替换字符图标：`○ 就绪`、`● 未保存`、`▸ 原文`、`＋ 导入` 等，改为「矢量图标 + 文字」；`✓` 用 `check.svg`。
- 图标在深浅两套下用同一路径、运行期着色（§4.3-3）。

### 8.3 控件与状态
- 输入框：去掉「靠 `#F8F8F8` 底与白纸 1.06:1 区分」的做法，改 **1px 底线 `ruleStrong`（3.6:1）**，聚焦时底线 2px `ink`；视觉更轻，也满足非文本对比。
- 状态胶囊：`ink` 小圆点 + 文字（就绪/处理中/未保存/失败），不再用 `○●` 字符。
- 按钮层级收敛为：主（实心 ink）、次（`muted` 底）、弱（纯文字）、危险（P2 再引入）。
- 焦点环：2px `focusRing` + 2px offset，键盘可见，鼠标点击不显示。
- 空 / 加载 / 错误三态：列表空态一句话 + 主按钮；页面加载用骨架条；失败用一行 `ink` 说明 + 「重试」。

### 8.4 动效
- hover 120ms、按下 80ms、面板折叠 180ms、气泡高亮脉冲 240ms。
- 只做透明度/位置，不做缩放（避免布局抖动）。
- 「减少动效」开关（设置页，P2）时全部降为 0ms。

### 8.5 高 DPI
- 图标按 DPR 渲染，把手 ≥10 设备像素，1px 线条用 cosmetic pen。
- 200% 缩放下复核 820×480 布局（现有验收要求）。

## 12. 风险与回滚

| 风险 | 影响 | 缓解 |
|---|---|---|
| 自绘控件漏改颜色 | 深色下出现白块/黑块 | 全局检索 hex 的 CI 检查（新增一条 grep 断言：`ui/` 内除 theme.py 外禁止 `#RRGGBB`，白名单注明数据色） |
| 画布重写破坏蒙版拖拽 | 高（核心编辑能力） | 先抽 `RegionOverlay`，保证精修相关回归（`test_editor_live_preview` 39 项、`test_large_editor` 9 项、`test_desktop_ui` 20 项）全绿后再替换视图；拖拽矩阵逐条手测 |
| 右栏改造影响保存/切页草稿 | 高 | 只动布局与信号连接，不动 `_store_properties`；切页/切块回归用例必须通过 |
| `QPlainTextEdit` 不支持 CSS 行高 | 视觉不达预期 | 用 `QTextBlockFormat` 或改 `QTextEdit`；先在 P1-1 做 10 行原型验证 |
| 深色下漫画观感被影响 | 中 | 页面像素零改动；只改周边；提供「画布底色」三档让用户自选 |
| 文档截图与真实界面不一致 | 中（误导用户、直接劝退） | review 脚本加字体断言；P0-0 后用正常字体重出 README 与 docs 图 |
| i18n 漏译 | 中 | 新增键必须同 PR 补 en/ja；语言检查脚本跑一遍 |

回滚：每个任务单独 commit，按 ID 可独立 revert；主题默认值保持「纸白」，深色为显式选择或跟随系统，出问题可一键退回浅色。

## 13. 给作者的反馈

### 13.1 用户原话（保留）
1. 「精修时，预览漫画的画布不能像 PS 那样可以用鼠标拖拽和缩放大小，只能用滑条，来回换比例也不方便。」
2. 「文字与排版窗口特别小，我这只能看到 3 行。」
3. 「画布的气泡无法通过点击切换编辑对象，因为 2 所以只能来回滑动文字与排版窗口切换气泡。」
4. 「要是有夜间模式就好了，全白界面看久了非常的刺眼。」

### 13.2 复现与影响（我核对后的技术描述）
| # | 复现 | 影响 | 建议 |
|---|---|---|---|
| 1 | 精修页 → 工具栏「适应页面」下拉 → 只有「适应页面」+ 4 档倍率；画布上拖动无反应，滚轮只滚页面 | 高频操作（每次核对字号/位置都要缩放），一天几十次 | 上 §5 手势；至少先加 Ctrl+滚轮 + 空格平移 |
| 2 | 打开 20 块以上的页 → 右栏列表只显示 2–3 行；中文长句输入框要内部滚动 | 校对效率低，容易漏改 | §6 右栏重构；先放开列表高度到 220px 也能立刻缓解 |
| 3 | 想改画布上第 5 个气泡 → 只能在列表里滚动查找；窄窗下列表还被自动滚出视野 | 与 2 叠加，成为最烦的一点 | §7 点选；这是「少一次滚动」的体验，不是新功能 |
| 4 | 长时间使用全白界面；设置里没有主题项 | 眼睛疲劳，夜间不可用 | §4 深色主题 |

### 13.3 我另外发现的问题（建议一并排期）
1. **窄窗文字被裁**：850px 下导航「02 Typesetting」被裁成「ypesettin」、「连续长条」显示为「ontinuous stri」、页签「Transl…」「Layout_position」被截断（`large-editor-en-editor-850-scale-1.png`）；工具栏只是把它们挤在一起，没有 elide 或收进菜单。
2. **侧栏静默消失**：<1120px 自动收起一个侧栏，只有 tooltip 解释，用户会以为面板丢了（`editor_page.py:552-573`）。
3. **「刷新预览」多余**：修改已实时预览，按钮仍占主操作位（`:483-492`）。
4. **选区视觉偏弱**：蒙版虚线 `#607D8B` 对白纸 4.37:1、1.5px 虚线，在网点背景上容易看丢；7 逻辑像素的把手在 4K 100% 缩放下只有 7 设备像素。
5. **列表信息量不足**：只显示编号 + 前 28 字，没有「已还原/手改」状态，长句被硬截。
6. **无跨块撤销**：只有「撤回修补」，文字改动没有撤销栈（输入框内有局部撤销）。
7. **图标可见性**：3 个 SVG 写死 `#111111`，一旦上深色会直接消失（所以深色必须先做图标着色）。
8. **输入框边界对比不足**：`#F8F8F8` 底对白纸仅 1.06:1，弱视/低亮度屏幕下几乎看不出输入区（建议按 §8.3 改底线）。
9. **文档截图的字体是错的**：`scripts/review_large_editor_ui.py:10` 强制 offscreen，Qt 枚举不到系统字体，整个界面回退到内置手写体 Aa；README 与 `docs/ui-review/` 的一批图因此看起来花哨。正常桌面是微软雅黑（本机已验证），但图错就是错，而且缺系统字体时的回退本身也没有兜底。建议 P0-0 先修，并重出对外图。

### 13.4 建议回复口径（可直接用）
> 四条都收到了，也都复现了。①②③ 是同一个问题的三个面：精修页的「画布 + 右栏」还是按小图校对设计的，撑不住长篇。④ 会作为独立主题做完，不是简单反色。
> 排期：先做画布手感（滚轮/拖拽缩放）和夜墨主题，再做右栏空间与画布点选；都是精修页内改动，不动排版算法和导出结果。
> 附带修掉：窄窗文字被裁、侧栏静默消失、刷新预览冗余、选区太细看不清。
