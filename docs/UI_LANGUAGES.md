# 界面语言

ComiTrans 提供三种界面语言，中文为默认值：

| 选择 | 配置值 |
| --- | --- |
| 中文 | `zh-CN` |
| English | `en` |
| 日本語 | `ja` |

首次正常打开时会显示三语语言选择窗口。选择后点击“继续 / Continue / 続行”，主界面立即使用该语言，然后才开始模型预热。关闭选择窗口则使用中文。选择成功保存后不再重复询问；升级后尚未选择过界面语言的配置也会出现一次。

之后可进入 **设置 → 翻译服务 → 界面语言**，选择语言并点击 **保存配置**。设置页会提示下次启动生效；完成当前工作后关闭并重新打开即可。翻译任务、已加载的模型和未保存的精修草稿在保存该设置时保持原样。

界面语言与漫画的原文语言、OCR、简体/繁体译文选项分别保存。选择 English 或日本語不会把漫画译文改为英文或日文，也不会改动译文内容、字体引用或输出文件名。字体专名和原始运行日志保留原始内容；页面、菜单、按钮、说明、工具提示、动态计数及应用弹窗随界面语言显示。

界面语言写入现有 `config.yaml` 的 `ui_language` 和 `ui_language_selected` 字段，保留其它配置。语言选择写入失败会提示错误，当前启动仍可使用所选语言；设置页保存失败会保留待保存的选择。

界面文案目录为 `assets/i18n/en.json` 和 `assets/i18n/ja.json`，无需联网。中文直接使用源码文案。Qt 原生按钮使用随程序提供的 `qtbase_zh_CN.qm`、`qtbase_ja.qm`；英文使用 Qt 默认文案。发行检查同时要求两个应用语言包和这两个 Qt 语言资源，避免生成缺少语言资源的程序包。

`--smoke-test` 跳过首次选择，不阻塞自动检查。直接构造界面用于测试同样不会弹出首次选择窗口。
