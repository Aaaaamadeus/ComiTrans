# 多模态翻译约束与本地字体协同计划

2026-10-08。本轮完成右上角日文字体修复，并制定以下方案；翻译和字体自动选择逻辑尚未按本方案改动，也未发起新的付费模型评测。

## 判断与现状依据

建议优先改善多模态翻译的输入组织、输出校验与上下文，再逐步开放受限字体选择。提示词有价值，但必须与可验证的输入、代码约束和真实漫画评测配合。

- `translate_page_batch()` 目前发送编号 OCR 文本和整页图，返回 `translations` 字符串数组。已有名称对照、源语言、语气规则、JSON 模式及截断续译；缺少文本块与局部图像的明确对应、跨页术语记忆和独立的不确定状态。数组数量正确仍可能串块。
- `prepare_comic_page()` 已产生框、方向、字号、角色、笔画强度及部分 OCR 置信度，可直接复用；没有置信度的后端不能假装提供可靠概率。
- `font_probe.py` 已有三候选图、A/B/C/none、角色许可表和投票。项目的 [真实页记录](FONT_STYLE_STRATEGY.md#414-真实页手动测试a-在真实裁切上不稳定功能默认关闭) 显示真实页会不一致；[成本复盘](FONT_STYLE_STRATEGY.md#415-成本复盘与改造账单主要由思考-token造成) 也记录了多数票仍选错，不能把投票当成正确性的证明。
- 候选与落地字体有偏差：黑体候选优先用 `bold_dialogue` 的实际字体，普通对白选中后却映射成 `lxgw_marker`；手写候选优先用 `tegaki_851`，落地却可能用 `handwriting`。改为选择实际候选 ID 后，应使用该候选对应的同一文件与风格。
- `PRECISION_GATE` 当前三族均写为 1.0，来源是小规模合成样本，不能代表真实页正确率。需要按实际模型、字体候选和真实样本校准。
- `vertical_typesetter.py` 已有字形覆盖检查、回退与本地字号适配，应保留并用于候选预筛选。

官方 OpenAI 文档指出小字、日文和精确空间定位存在局限，因此建议用整页提供场景，用局部裁切提供文字证据，块对应关系交给本地建立。这是针对本应用的设计推断，需要在当前接入的模型上验证。[Images and vision](https://developers.openai.com/api/docs/guides/images-vision)

## 多模态输入与翻译约束

本地创建稳定的 `page_id/block_id`，将阅读顺序、原始 OCR、块框、局部裁切、可用的 OCR 置信度、用户术语表一并组织。整页保留上下文，高清裁切只给低质量或歧义块，控制请求体与图像成本。阅读顺序先校验，编号不靠模型自行猜测。

跨页记忆只保存用户指定或确认过的名称、术语与少量必要对白；不积累模型猜测的剧情摘要。并行任务使用固定版本的术语表快照，合并时检查冲突，避免页面先后完成导致名字漂移。

拟采用的核心翻译提示词：

```text
你是漫画本地化译者，将指定文本块译成自然、简洁的简体中文。
输入包含：用户确认的术语表、整页上下文、带 ID 的 OCR 文本，以及部分块的局部裁切。

1. 每个输入 ID 必须恰好返回一次；不得遗漏、合并、新增、改名或将译文放到其他 ID。
2. 用户确认的名称与术语优先。整页图用于理解语气、指代和场景，不能凭画面补写没有文字证据的对白。
3. OCR 是转录结果，局部裁切清晰可辨时才允许纠正 OCR；保留原始 OCR，并记录发生了纠正。
4. 看不清、OCR 与图片冲突且无法判断时标记 unclear，译文留空，交给人工检查；不要编造。
5. 保留原句的信息、语气、敬语、否定、数量与情绪；简洁不能以删掉重要含义为代价。
6. 日文振假名仅辅助读取正文，不单独重复翻译。拟声按语义译成中文；纯标点或无需改写的块标记 keep_original。
7. 不确定的说话人或称呼保持中性表达，不根据人物外貌猜姓名、性别或关系。
8. 排版容量是软约束；优先完整表达含义，不能为了字数上限杜撰缩写或删除信息。
9. 只输出约定 JSON，不输出说明、字号、字体名、坐标或排版方向。
```

输出草案（格式尚未落地）：

```json
{
  "items": [
    {
      "id": "p001-b003",
      "translation": "我们从这一页开始吧。",
      "status": "ok",
      "flags": []
    }
  ]
}
```

`status` 限定为 `ok/unclear/keep_original`，`flags` 用有限枚举，例如 `ocr_corrected/ocr_conflict/term_ambiguous`。证据不清或保留原文的块不参与擦字，保留原稿供精修；是否清晰不能依赖模型自报 confidence。

加入少量真实例子，覆盖主语省略、敬语、拟声、振假名、OCR 冲突与弃权，避免只给理想对白。示例的价值需要 A/B 验证；官方提示工程文档也建议例子覆盖不同输入。[Prompt engineering](https://developers.openai.com/api/docs/guides/prompt-engineering)

支持时使用严格 JSON Schema；不支持的兼容接口沿用 JSON 模式并执行本地字段、类型、ID 集合与状态校验。Schema 约束输出结构，语义仍会出错，不能把合法 JSON 当作翻译正确。[Structured model outputs](https://developers.openai.com/api/docs/guides/structured-outputs)

## 本地与模型怎样选择字体

| 阶段 | 本地职责 | 模型职责 |
| --- | --- | --- |
| 证据准备 | 使用文字掩膜和行框，区分正文、振假名、字重及背景网点；几何与检测结果给出基础方向、字号和角色 | 翻译阶段理解语气与指代；字体阶段不改译文 |
| 候选预筛 | 从用户配置的实际字体建立覆盖率与族信息；检查译文字形可用、角色许可及试排；留下 2–3 个有效候选 | 无 |
| 受限比较 | 将原字块与实际候选渲染图配对；保存本次候选 ID、风格、路径与文件指纹 | 只选 A/B/C/none，比较笔画端点、字脚、圆角和手写变化 |
| 采纳与排版 | 检查结果合法、候选仍有效、真实评测门槛与本地证据；使用选中的同一字体；控制字号、换行、缺字回退与输出 | 无 |

对照图可以同方向、相近单字尺寸，用原文比字形，用译文做覆盖和试排；不能比较一款字体却输出另一款。候选位置在评测中轮换，检查模型是否偏爱固定字母。

字体比较提示词草案：

```text
上方为原图文字块，下方为 A/B/C 候选。
比较字形的笔画端点、字脚、圆角及不规则手写变化。
候选已尽量统一文字、方向和单字尺寸；不要因内容、背景网点、位置或标签字母做选择。
不清晰、不能可靠比较或都不接近时选 none。
仅返回 {"pick":"A"}、{"pick":"B"}、{"pick":"C"} 或 {"pick":"none"}。
不得返回字体名、字号、方向，也不得改写对白。
```

裁切提取笔画特征与振假名分离应先做样本验证，不假定二值化、去网点一定改善结果。装饰类、标题与拟声保持已有角色门控，第一版只改正文与手写类。

仅对本地证据不足的块调用模型，设置页面调用数和 token 预算；同块最多补一次比对，冲突即弃权，超时或无结果采用本地字体。缓存包含裁切、文本、方向、候选文件指纹、模型及提示词版本；复用前仍检查当前译文覆盖率。投票仅作为稳定性信号，真实错误率决定是否采纳。

## 实施顺序与验收

1. **建立基线与数据集。** 选择 20–30 页、至少 200 个真实块，覆盖正文、手写、拟声、竖排、小字、网点与振假名；每个待开放字体族至少 30 个真实块。将调试集、校准集、留出验收集按作品分开，人工标注译文问题、术语、字体族与可接受中文风格。
2. **先落地翻译提示词与 ID 契约。** 提取提示词构造器，接入块元数据和分辨率预算，给有歧义的块加局部裁切；新增 ID 校验、unclear 状态与必要术语记忆。页面级结果随任务传递，避免共享可变 last-result 字段导致并发串页；兼容现有列表输入与旧布局 JSON。
3. **修正字体候选与最终字体的一致性。** `font_probe.py` 返回实际候选 ID；本地检查译文字形覆盖与角色许可，渲染所选的同一字体。复用现有 typesetter 的回退与字号适配。
4. **增加受限联动、缓存和预算。** 保留实验开关默认关闭；本地有把握时直接排版，歧义块才比较，none/冲突/超时回退。记录每次采纳的来源和回退原因供精修查看。
5. **进行真实 A/B 评测。** 比较现有版本、约束提示词版、加局部裁切版、字体协同版；评估错块/漏译、语义忠实与自然度、术语一致、误换字体、缺字/溢字、耗时及 token 成本。人工盲评为主，模型评分为辅助，不能只比较模型自报分数。
6. **达标后分族开放。** ID 契约错误、新增缺字与溢出作为硬性不通过项；译文盲评优于基线；字体族须在留出集改善风格贴近度且误换率建议不超过 5%，结合样本量审查后才开放。不足的族继续采用本地结果，不沿用合成 5/5 推出的 1.0 门控。行级混排另立阶段，并先区分振假名与真正的强调变化。

优先级：输入对应与翻译质量 → 候选实际字体一致 → 字体选择实验 → 真实评测 → 默认行为调整。
