- 真实训练样本来自 [JustANormalTinkerer/animetext-ocr](https://huggingface.co/datasets/JustANormalTinkerer/animetext-ocr)（revision `9c70c6b`；序列置信度 0.85–0.98 的日文裁图），数据集声明为 CC BY-NC-SA 4.0。训练只用其文字标签；逐字框起初取自 manga-ocr-charspot-nano 的输出，之后由本模型在训练中自己生成。

## English

- Code is licensed under Apache License 2.0 (`LICENSE`); this does not cover the model weights. Model weights (`model.safetensors`, `model.onnx`) are licensed under CC BY-NC-SA 4.0 (`LICENSE_MODEL`); commercial use requires separate permission.
- The model was trained from random initialisation; no pretrained weights were used.
- Real training samples derive from [JustANormalTinkerer/animetext-ocr](https://huggingface.co/datasets/JustANormalTinkerer/animetext-ocr) (revision `9c70c6b`; Japanese crops with sequence confidence 0.85–0.98), declared under CC BY-NC-SA 4.0. Only its text labels were used; character boxes first came from manga-ocr-charspot-nano's output and were then produced by this model itself during training.
- The images of that dataset come from AnimeText ([arXiv 2510.07951](https://arxiv.org/abs/2510.07951)). The real kana glyphs used by the synthetic handwriting were also cut from AnimeText images and upscaled 4× with [Real-ESRGAN](https://arxiv.org/abs/2107.10833) (RealESRGAN_x4plus_anime_6B); this package does not contain those glyphs.
- Synthetic training data (including the synthetic long text) was generated by the project renderer from text of the author's private manga collection, which is not published. This package contains no training images, font files or AnimeText-OCR images.
- No image from the JMangaBench_Read candidate pool or benchmark was used for training; Read v1.2 served as the development set (checkpoint choice, error analysis).
- The crops in `samples/char_boxes.png` are from [JMangaBench_Read](https://github.com/muscgab/JMangaBench_Read) (CC BY-NC-SA 4.0).
