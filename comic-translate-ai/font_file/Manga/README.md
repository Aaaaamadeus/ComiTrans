# 漫画强调与空心字：简繁配套字体

这两组字体用于接近用户提供的漫画字样风格，**不是对原日文字体名称的鉴定，也不是原字体的官方中文版**。原图尺寸和可辨字符太少，无法确认原字体。第一张为粗重、略有墨团感的字；第二张为圆润白心黑边字，需要字体和描边共同实现。

| 参考风格 | 近似字体 | 简体文件 | 繁体文件 | 精修文字效果 |
| --- | --- | --- | --- | --- |
| 粗重强调字 | [狮尾 B2 黑体](https://github.com/max32002/swei-b2-sans) Black | `SweiB2Sans/SweiB2SansCJKsc-Black.ttf` | `SweiB2Sans/SweiB2SansCJKtc-Black.ttf` | 黑字白边 |
| 圆润空心字 | [狮尾牙膏圆体](https://github.com/max32002/swei-toothpaste) Black | `SweiToothpaste/SweiToothpasteCJKsc-Black.ttf` | `SweiToothpaste/SweiToothpasteCJKtc-Black.ttf` | 白字黑边（空心） |

SC / TC 分别采用作者提供的简繁地区字形，均保持原始 TTF 不变。四个字体共 61,437,452 字节（约 58.6 MiB），首次使用即可离线选择。原作者 README、SIL OFL 1.1 许可证和字体内嵌声明一并保留；`manifest.json` 固定上游提交、来源地址、文件体积和 SHA256。

应用字体选择框可搜索“狮尾B2”“牙膏”“简体”“繁体”以及原始英文名。选择字体不会自动替换当前文本的简繁字符，文字内容与字形地区版本分别选择。
