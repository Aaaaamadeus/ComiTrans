# 内置繁体漫画嵌字字体

10 个系列、12 个完整 TTF/OTF 文件，随应用发行并离线可用。字体原文件保持不变。

- [源泉圓體 TW](https://github.com/ButTaiwan/gensen-font)：日常對白、加重語氣。
- [jf open 粉圓](https://github.com/justfont/open-huninn-font)：輕鬆對白、可愛語氣。
- [芫荽](https://github.com/ButTaiwan/iansui)：柔和對白、內心獨白。
- [霞鶩文楷 TC](https://github.com/lxgw/LxgwWenkaiTC)：自然對白、敘述文字。
- [內海字體 TW](https://github.com/max32002/naikaifont)：手寫對白、氣泡外的小字。
- [清松手寫體 3](https://github.com/jasonhandwriting/JasonHandwriting)：吐槽、呆萌語氣、手寫註記。
- [思源黑體 TC](https://github.com/adobe-fonts/source-han-sans)：中粗對白、喊叫、強烈語氣。
- [思源宋體 TC](https://github.com/adobe-fonts/source-han-serif)：旁白、正式敘述、嚴肅氣氛。
- [獅尾加糖宋體 TC](https://github.com/max32002/swei-sugar)：驚叫、恐怖氣氛、擬聲大字。
- [大波浪圓體 TC](https://github.com/max32002/pop-gothic)：撒嬌、搞笑、可愛擬聲字。

每个目录保留上游说明、许可证与原字体内嵌声明。清松字体的作者授权在 README 与内嵌版权中，另附 SIL 官方许可证参考原文，详见 06-Jason3/LICENSE-NOTE.txt。

manifest.json 记录来源版本、SHA256 与字符测试；fonts[].file 相对于本目录。
完整用途和兼容性说明见项目 docs/TRADITIONAL_MANGA_FONTS.md。
